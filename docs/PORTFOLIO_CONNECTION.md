# Portfolio Connection

## Role of this project

Within Alfredo Martín Gil's Clinical AI portfolio, the Clinical Reflection Band (CRB) is the **research-concept** asset. It shows how a clinically motivated question can be translated into an explicit architecture, boundary conditions, failure modes, and a staged evaluation proposal.

It should not be presented as a software product or clinical implementation.

## Three-project narrative

### 1. Applied prototype

[`clinical-nlp-triage-open-source`](https://github.com/Alfredo-Martin-Gil/clinical-nlp-triage-open-source) demonstrates auditable prototype work with synthetic data, documented limitations, evaluation logic, and human-oversight boundaries.

### 2. Research concept

**Clinical Reflection Band** examines a complementary problem: how a future system might surface possible instability in the frame guiding care without diagnosing, recommending, or transferring authority. Its contribution is conceptual and research-oriented.

### 3. Clinical-operational foundation

[`prehospital-clinical-decision-uncertainty`](https://github.com/Alfredo-Martin-Gil/prehospital-clinical-decision-uncertainty) grounds the portfolio in prehospital workflow, incomplete information, time pressure, and state uncertainty.

## Connecting logic

The three assets form one implementation-oriented narrative:

- **workflow problem:** clinical decisions occur under uncertainty and incomplete state capture;
- **applied artifact:** prototypes must be auditable and evaluated for failure behaviour, not presented as clinical systems;
- **human-factors and governance question:** AI support must preserve authority, expose limitations, and be evaluated for false reassurance and signal burden.

This narrative supports the positioning **Clinical AI & Healthcare Implementation Physician** by demonstrating clinical problem framing, evaluation discipline, human oversight, safety-boundary reasoning, and communication across clinical, research, product, and technical teams.

## Professional description in English

> Clinical Reflection Band is a research-stage conceptual architecture exploring whether non-directive AI cues could surface tension between a clinician's active interpretive frame and a patient's observed trajectory. My contribution is the clinical problem framing, system-boundary design, failure-mode analysis, and proposed validation pathway. The repository contains no implemented or clinically validated system and is not intended for patient care.
